# Simple Temperature Classifier

This project classifies temperatures into different categories using Python.

## Temperature Categories

- Below 15°C - Cold
- 15°C to 25°C - Normal
- 26°C to 35°C - Warm
- Above 35°C - Hot

## Example

10°C = Cold

20°C = Normal

30°C = Warm

40°C = Hot
